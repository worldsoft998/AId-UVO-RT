# AId-UVO-RT
AI-Driven Universal Verification Optimization (Runtime/Instantaneous - AId-UVO-RT)

A project-agnostic, universal, AI (Reinforcement Learning)-based, Coverage-Driven Hardware RTL verification acceleration / optimization framework / module (the optimizer) to observe, understand, and steer the verification environment dynamically at runtime and also as a blackbox at post-run,  both capable of Real-Time Optimization.
